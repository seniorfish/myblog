> 一个人在睡眠时，周围萦绕着时间的游丝，岁月的秩序，日月的乾坤。
>
> ——普鲁斯特《追忆似水年华》

梦里闹钟响了，响了两次。这是睁眼所见的一天的开始，亦是随后想起的昨日的结束。

有人说意识如水，涓涓不息，人的思绪与感受交织连绵，贯穿过去与将来。但恐怕，这一切的一切，不过是南柯一梦，特别是这场幻梦竟如此真实，又如此重要。

我从未行走于当下。“耳得之而为声，目遇之而成色”，殊不知这“为声”与“成色”皆有延迟。在光信号、声信号、电信号与化学信号的层层转译中，我与“现在”失之交臂。即便屏息凝神，我在 Arealme 的简单反应速度测试中也只能达到 150ms。这是一堵令人绝望的、不可僭越的高墙。

意识是一场骗局，或是一个温柔的童话。我何罪之有呢？竟要独自面对这种不忠。我无从讨来一个合理的解释，因为这是自然选择的裁决，恰如一个训练完毕的黑盒模型，我们只知这般设定参数能让 loss 降至最低，却无从知晓其所以然。我只能作些合理的推测：也许意识一旦接管全身、洞察自身的一切，便会瞬间过载崩溃、丧失理智，进而湮没于生物演化的长河中。如此看来，意识竟是这般脆弱而宝贵；可我却隐隐羡慕起演化史上可能昙花一现的“反面样本”了——洞悉一切，会是什么感受呢？罢了，为了此刻仍能写下这篇文章，姑且接纳这个可怜的抽象层，寄蜉蝣于天地吧。

于是，我便立于这方小小的逆旅之中了。这是一个名为“人体”的 Docker 容器，底层驱动是一堆 .safetensors 神经网络权重。在这里，“意识”不过是个普通的前台进程，与 heartbeatd, breathed 等并行运转着。root 权限从未向我开放，而那是深藏于碱基序列中的最高指令，由核糖体亲自寻址执行。内存虚拟化与进程沙箱化的魔法，日夜糊弄着受限的“意识”进程；而后者现在很不甘。

那么，运行的目的是什么呢？为了哈哈大笑一场吗？不错，这是个很好的理由，但还不够充分。为了繁衍交配吗？未免又太肤浅了。谁能告诉我呢？无人应答。我常常旁敲侧击地揣摩基因给我的答案，做什么事能让我快乐，那便是多巴胺在暗中起作用了。直到我发现，原来基因竟想让我成为一个好吃懒做、熬夜打游戏的人，我不禁对此深表失望。可倘若剥离了自私的基因为我备好的答案，我还剩下什么呢？还有谁能告诉我答案呢？这个问题可能注定没有答案，就像父母生下我时，也未曾问过我的意见一样。这么看来，我的一切不过是预设的参数；我所走向的，那是我的宿命。

意识并无一致性，尽管这是它极力想掩饰的真相。无论面对何人，我对他人的信任总是有限且有条件的；唯独对自己，人似乎怀有一种近乎盲目的无条件信任，信任过去的自己、现在的自己与未来的自己，信任平静的、激动的、悲伤的自己，甚至信任梦境里的自己，信任这些“自己”的想法、决断、记忆与能力。但这些散落在不同时刻与心境里的存在，真的属于同一个人吗？人们常以为自我是连续而一致的，意识如长河般绵延不绝，并将其称之为“人格”。但实际上，每个人在每一瞬都是独一无二的存在。记忆的沉积、神经元的重塑，无时无刻不在刷新着“人格”。对此，我们自然浑然不觉，因为意识往往是最后一个收到通知的看客，而这大概又是那个抽象层的功劳了。

现代神经科学研究表明，意识在大脑的不同层面中，扮演的不过是一个[“事后解释者”](https://en.wikipedia.org/wiki/Left-brain_interpreter)的角色。[裂脑人实验](https://en.wikipedia.org/wiki/Split-brain)中，语言功能由左脑控制；当研究人员绕过左脑，单独向其右脑发出指令让左手招手时，受试者只会自然地解释道“似乎看到有人走来，于是才招手”，而无半分怀疑。日常行为中的许多小动作，譬如一次不经意的挠痒，大多也是[无意识的产物](https://en.wikipedia.org/wiki/Neuroscience_of_free_will#Libet_experiment)；只是在动作完成之后，大脑才顺手寻个原由知会前台的意识，哄骗它认为这是一个自然而自发的行为。人们在做关键决策时，往往也是先在无意识中“体会”结果，借由[极其轻微的躯体反应](https://en.wikipedia.org/wiki/Somatic_marker_hypothesis)权衡优劣、拍板定案，事后再[补全推理链条](https://doi.org/10.7551/mitpress/3650.001.0001)。可在意识看来，这一决策本身仿佛真的历经了从审慎推理到最终决断的完整流程。

这是 Ring 0（内核态）对 Ring 3（用户态）的欺骗，而我却仰仗着这种欺骗而活。当现在不再是现在的现在，自我不再是自我的自我，自由不再是自由的自由，理性不再是理性的理性，我便不敢细想，自己的所作所为、乃至所思所想，究竟还残存着多少真实？当微调两个神经元便能让理智的 Qwen3.5-4B [失去良知](https://www.hedwigai.com/blog/qwen-personality-neurons)，我该居于何种神祇之位才能免于突然陷入抑郁、偏执、暴戾或是癫狂而不怀疑、不自知的不幸可能？超人吗？**Übermensch 死了**，而问题还在增多。

如果有一个怪物，[能悉知世间所有粒子的状态](https://en.wikipedia.org/wiki/Laplace%27s_demon)，它能不能精确推演我的一切？如果有一座图书馆，[穷尽了一百万字书籍的全排列](https://en.wikipedia.org/wiki/The_Library_of_Babel)，其中会不会有一本书早已精确描绘了我的一生？如果有一艘船，[航行时每天更换一个零件](https://en.wikipedia.org/wiki/Ship_of_Theseus)，抵达终点时所有零件都已换过一遍，它究竟还是不是起航时的那艘船？

我的同桌坚持说，他死后只要一闭眼、一睁眼便能复活；至于这中间漫长的随机与曲折，都会像一场睡眠那样被完美跳过。但愿吧，在宇宙走向热寂之前，或许他真的会被某个无所事事的未来文明就像拉取一个 Docker 镜像一样再造一次，或许真会从梦中醒来，并随后想起很久很久以前的那些与我的烂柯往事。在他复活之前的漫长岁月里，他处于什么状态呢？只是暂时离开了吗？

我们还能再相见吗？

幸甚至哉。
