这是这个博客的第一篇文章。它同时是一份可运行的设计说明：内容只写 `.md`，时间来自 Git 提交与链上锚定，界面由独立的主题分支负责。

## 为什么是节点，而不是文章

传统博客把“文章”“想法”“收藏”拆成不同栏目。这里把它们统一成 **节点**：每条内容只有一个主 Tag，主 Tag 决定它在时间流里的形态，次 Tag 负责筛选与皮肤。

| 主 Tag | 形态 | 是否默认展开 |
| --- | --- | --- |
| 文章 | 长文 | 否，显示摘要与链接 |
| 想法 | 短卡片 | 正文不超过 400 字时展开 |
| 闪念 | 单行 | 是 |
| 收藏 | 外链卡片 | 否 |

## Frontmatter 只保留必要字段

```yaml
---
tags: 文章 建站
title: 构建面向 AI Agent 的个人博客
extends: optional-parent-id
---
```

日期字段是禁止的。`date`、`pubDate`、`createdAt` 这类字段会直接让编译失败，因为它们绕开了 Git 与链上的时间来源。

> [!NOTE]
> 每篇文章的“创建时间”不是作者填的，而是“最早一个包含它的锚定提交”的区块时间。没有锚定之前，页面会明确显示未验证状态。

